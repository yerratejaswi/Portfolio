About

I'm a software engineer with 4 plus years designing, shipping, and operating production distributed services across financial services and healthcare — Java and Spring Boot microservices on AWS and Kubernetes, event streaming with Kafka and RabbitMQ, and the CI/CD infrastructure that gets it all to production.

Recently that's meant engineering delivery pipelines that took 60% of the manual steps out of releases, decoupling services with Kafka to cut repeat incidents by 20%, and redesigning data models and query paths to drop P95 latency by 30%. I'm equally comfortable in the data model, the service that serves it, and the pipeline that ships it.

Alongside that I build applied-AI engineering tooling — most recently an autonomous agent that reads Kubernetes logs, retrieves relevant source via RAG, and opens remediation pull requests. I also run an independent research project applying machine learning to quantum error mitigation, in simulation, using Qiskit Aer.
